# Fotos de hábitats

Coloca aquí las fotografías reales de cada hábitat. Cada hábitat de
`Data/parks/murcia/cabo-cope-puntas-calnegre/park.json` ya apunta a su archivo
mediante el campo `image` (`Img/habitats/<id>.jpg`).

**En cuanto exista el `.jpg` con el nombre exacto, la etiqueta del hábitat lo
muestra automáticamente.** Mientras el archivo no exista, se muestra una portada
temática generada (degradado en el color del hábitat + emoji + código), así que
no hay imágenes rotas.

## Convención

- Formato: `.jpg` (si prefieres otro formato, actualiza el campo `image` del hábitat en `park.json`).
- Nombre del archivo: el `id` del hábitat + `.jpg`, tal cual la tabla de abajo.
- Recomendado: orientación horizontal, aprox. 800×460 px o mayor (se recorta a 380×220 en la ficha).
